# لاوین کیک: لندینگ

پیاده‌سازی لندینگ «لاوین کیک» با Next.js 16 (App Router)، React 19، TypeScript و Motion برای انیمیشن‌ها.

## اجرا

```bash
npm install
npm run dev      # http://localhost:3000
npm run build && npm run start   # نسخهٔ production
```

Node.js 20.9 یا جدیدتر لازم است.

## ساختار

```
src/
  app/
    layout.tsx        html با lang="fa" و dir="rtl"، متادیتا، پیش‌بارگذاری فونت
    page.tsx          چیدمان بخش‌ها
    globals.css       فونت‌ها، رنگ‌ها، دکمه‌های طلایی
    icon.png          فاوآیکن (لوگو)
  components/
    Header.tsx        هدر
    Hero.tsx          بخش اصلی
    DripDivider.tsx   نوار کارامل
    Menu.tsx          منو
    MenuRow.tsx       هر ردیف منو
    ZLine.tsx         خط طلایی بین ردیف‌ها
    Location.tsx      آدرس و راه‌های تماس
    icons.tsx         آیکن‌های SVG
  data/site.ts        همهٔ محتوا: تلفن، اینستاگرام، آدرس، آیتم‌های منو و قیمت‌ها
  lib/motion.ts       منحنی‌ها و الگوهای مشترک انیمیشن
  assets/images/      لوگو، عکس اصلی، کارامل، عکس کیک‌ها
public/fonts/         وزیرمتن و Noto Naskh Arabic (self-hosted)
```

## ویرایش محتوا

همهٔ متن‌ها در `src/data/site.ts` هستند. این مقادیر در دیزاین placeholder بودند و باید پر شوند:

- `price` هر آیتم منو (الان `[قیمت]`)
- `address` و `hours` (الان `[آدرس دقیق کافه]` و `[ساعت کاری]`)
- `mapsHref` (الان جستجوی کلی «Tehran» در گوگل‌مپ)

برای اضافه‌کردن کیک: عکس مربعی را در `src/assets/images/menu/` بگذارید، import کنید و یک آیتم به آرایهٔ `menu` اضافه کنید. چیدمان زیگزاگی و خط طلایی خودکار ساخته می‌شوند.

## انیمیشن‌ها

- **هدر:** لوگو با چرخش وارد می‌شود، لینک‌ها پشت سر هم ظاهر می‌شوند و دکمهٔ تماس با فنر بزرگ می‌شود.
- **هیرو:** هر خط تیتر جدا و با محو شدن blur بالا می‌آید. عکس با کمی چرخش جا می‌افتد، با حرکت ماوس tilt سه‌بعدی می‌گیرد و هنگام اسکرول آرام‌تر از صفحه پایین می‌رود (parallax).
- **کارامل:** موقع لود از بالا به پایین «ریخته» می‌شود و با اسکرول کمی کش می‌آید.
- **منو:** هر کیک مثل کیکی که روی پایهٔ گردان گذاشته شود چرخان وارد می‌شود. کارت متن از پشت کیک باز می‌شود و برچسب قیمت می‌پرد. خط طلایی همراه اسکرول کشیده می‌شود و کشیده می‌ماند.
- **هاور:** کیک کمی می‌چرخد و حلقهٔ طلایی‌اش می‌درخشد. روی دکمه‌های طلایی برق نور رد می‌شود و زیر لینک‌های منو خط کشیده می‌شود.
- **آدرس:** دکمه‌های تماس از چپ وارد می‌شوند و خط پایین صفحه از راست کشیده می‌شود.

همهٔ انیمیشن‌ها دقیقاً روی حالت دیزاین تمام می‌شوند. اگر کاربر در سیستم‌عامل «کاهش حرکت» (prefers-reduced-motion) را فعال کرده باشد، حرکت‌ها حذف می‌شوند.

## فونت‌ها

فونت‌ها همان فایل‌های Google Fonts هستند که دیزاین استفاده می‌کند، ولی داخل پروژه (`public/fonts`) قرار دارند. پس build و سایت هیچ وابستگی‌ای به سرورهای گوگل ندارند.
